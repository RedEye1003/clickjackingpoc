How to read this evidence

If the target site renders inside the frame above, it is missing framing protections and is vulnerable to clickjacking. The decoy button shows how an attacker overlays bait over a real control (e.g. a “delete account”, “transfer”, or “authorize” button) so the victim clicks the hidden action.

If the frame stays blank, the browser blocked it — the site sets X-Frame-Options: DENY/SAMEORIGIN or Content-Security-Policy: frame-ancestors 'none'/'self'. That is the fix.

Verify the headers directly: curl -I https://target.example.com and check for X-Frame-Options and frame-ancestors. Use the overlay opacity slider at 0 for a clean screenshot of the decoy fully covering the target, or raise it to show alignment.
